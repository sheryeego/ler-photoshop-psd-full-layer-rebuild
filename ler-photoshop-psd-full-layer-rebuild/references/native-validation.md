# 保存后原生验收

生成或修改 PSD 时执行。静态检查、真实编辑验证、视觉检查和交付一致性分开记录，不能互相替代。

## 保存并重开

记录主文件 SHA-256、尺寸、实际制作软件、版本、调用通道、输入与输出清单。主文件保存为默认成品，参考组和素材总览组隐藏。用选定软件重新打开最终 PSD；可复制到本次 QA 新目录，核对字节哈希一致，再打开副本。

PhotoCraft 使用 `info` 读取保存后的 PSD、`convert` 渲染预览，并在独立副本用 `run` 实际修改文字、移动主体和导出智能对象源；[PhotoCraft 操作参考](photocraft-automation.md) 记录主动选层等必要细节。只读取 `.pcraft` 中间文档不能替代重开最终 `.psd`。若最终还要求 Photoshop 兼容，另外在 Photoshop 重开验收，分别记录软件结果。

保留用户文档和先前活动文档；只关闭本次 QA 打开的文档，不保存测试改动。

## 编辑能力

| 检查 | 必需证据 |
|---|---|
| 默认视图 | 重开显示正常，参考图或总览没有覆盖成品 |
| 原生文字 | 所有文本内容和字体对照；每类代表层实际改字并恢复 |
| 完整智能对象 | 每种实际使用的主素材进入内部，检查源尺寸、轮廓、底部、遮挡处和真实透明度 |
| 嵌入状态 | 检查主文档及嵌套源，记录嵌入、链接或未知；未知不算通过 |
| 主体/装饰 | 每个主要独立对象可以移动；关闭外部蒙版后保留完整源内容 |
| 背景 | 隐藏或移开对象后检查空洞、旧主体轮廓、修补接缝 |
| 光影/粒子 | 独立开关、移动、改变强度，核对混合模式、作用区域和分组粒度 |
| 图层复合 | 逐个切换并导出，最后返回默认视图，无遗留参考/总览 |

需要边缘与局部放大检查，不能只看缩略图。单一图示按合理单元检查；源画布尺寸超过任意阈值不代表素材完整。

源照片保真区域可比较不透明 RGB 与 alpha。存在 AI 修复、抗锯齿或授权色彩修改时，限定区域、说明预期变化。不可见结构需要视觉判断和补全记录。

## 视觉与文件一致性

- 原图与重建对照用于评估还原，揭示布局、缺字、缺主体和遗漏光效。字体渲染及 AI 补全差异应明确说明。
- 重开 PSD 导出的默认预览应与交付预览一致。可比较解码后的像素；PNG 字节数相同不代表图像相同，文件哈希不同也不一定表示像素不同。
- 使用同一复合、画布、色彩转换和导出参数。有损 JPG 采用合理误差与视觉检查，不能称为逐像素一致。
- 接近原图和保存后预览一致是不同结论，分别记录。

## 状态与交付

[验证记录模板](../assets/validation-report.template.json) 默认为 not_run。没有适用对象写 not_applicable 并说明原因；未执行写 not_run；失败写 fail；观察到满足标准才写 pass。

所有用户要求的关键项通过才报告完整完成。能力受限或字体缺失时继续可做部分，具体报告剩余项。多层文件、检查脚本通过或智能对象数量均不能单独证明完整重建。

工作区保留主文件、预览、对照、实际素材总览、中文编辑说明和验证记录。最终交付范围优先遵守用户要求；不将整个工作区或测试副本复制到成品目录。哈希清单确认文件版本，不替代编辑验证。

## 备份

```powershell
python -X utf8 '<skill目录>\scripts\package_skill.py' --skill-dir '<skill目录>' --output-dir '<备份目录>'
```

脚本只打包指定 skill 文件夹，附带 manifest.json、SHA-256 和恢复说明；不扫描仓库、不上传、不删除、不覆盖旧包。生成后重读 ZIP 逐文件校验，并写外部验证报告。遇到符号链接或目录联接停止，避免范围外内容。

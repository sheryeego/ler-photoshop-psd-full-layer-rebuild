# 补充规则索引

只应用本次图片触发的项；当前用户说明优先。新案例可以独立追加，无需重写全部流程。

| ID | 适用情况 | 处理与验收 |
|---|---|---|
| S01 | 人物、动物、道具被遮挡或出画 | 按需求补全身体、肢体、轮廓和底部，保留可见身份、服饰、Logo；完整源用于默认成品，外部蒙版构图，标明推断部分。 |
| S02 | 金属奖杯、徽章、艺术字或海报氛围 | 检查边缘闪光、暖光、光束、细粒子及散焦光点，类别和数量随原图；艺术字双版本说明差异和切换。 |
| S03 | 店铺长图、网页截图或商品轨道 | 核对真实尺寸和排列；取得完整源，右侧裁掉卡片保留完整图片及标签，通过轨道外部蒙版裁切；主图内部排版的处理按本次需求。 |
| S04 | 纯色底、透明底或完整图示 | 保持底板形式，不新增场景或不存在的粒子；按移动需求拆图示，说明内部未拆范围。 |
| S05 | 精确商品、Logo、品牌资产 | 原始素材优先；记录允许 AI 修改区域与保真区域，放大核对接口、拉链、提手和商标；正式 SKU 主图生成仍遵守所属项目流程，不授予发布权限。 |
| S06 | 玻璃、薄纱、半透明塑料、毛发、反射 | 检查 alpha、边缘污染和透过物体的旧背景；记录反射/内在光照是否独立，不能用黑白底冒充透明。 |
| S07 | 字体缺失、文字不清或字重异常 | 核对源设计和真实字体样式；不编造文字或静默替换指定字体，批准替代时说明外观差异。 |
| S08 | 已有 PSD 只补一类内容 | 新版本保存，保留已接受构图；新增独立组和关闭效果复合，对比关闭新增组后与原版本，确认无无关变化。 |

## 案例边界

足球海报 v7 的光晕、金属闪光、细金尘、近景粒子和散焦光点可以作为检查思路，不能将历史的 6 个光晕、8 个闪光、189 个粒子变成固定要求。

FOXBOX 长图曾指定 Manrope SemiBold 600 / Medium 500 / Regular 400、商品卡 Segoe UI、商品主图内文字保留。只有本次要求一致时才沿用。

完整商品主图单元与透明商品主体是不同编辑粒度。需要移动照片里的商品时，必须拆出商品并修复背景，不能仅提供整张主图智能对象。

## 后续补充格式

先将用户补充用于当前授权任务；用户要求持久更新 skill 时再增加唯一 ID，记录：

1. 触发条件和适用范围。
2. 必须保持的内容和允许改动/AI 补全的区域。
3. 处理原则及可观察的验收条件。
4. 来源、确认日期、状态：已确认规则 / 待验证假设 / 已实测。
5. 是否替代旧规则，以及未验证的边界。

假设不写成必做规则；冲突按用户最新要求处理并更新被替代条目。
